OpenTable Static Analysis Rulesets
==================================

Component Charter
-----------------

* Provides custom PMD and SpotBugs rulesets for builds

Rulesets
--------

* `otj-pmd-rulesets/ot-pmd.xml` contains the shared PMD policy.
* `otj-spotbugs-ruleset/ot-spotbugs-exclude.xml` contains shared SpotBugs exclusions.

Component Level

*Foundation component*

* No code here, just configuration. Feel free to submit a PR
